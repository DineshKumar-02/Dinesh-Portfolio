The Spark of Coding

I started my coding journey in my 2nd year of college. Java was the first language I picked up, which opened my eyes to object-oriented concepts and logic building. It taught me how computers structure data and process instructions.

  • Focus entirely on core fundamentals first.

Development 2025

My First Web App Struggles

Transitioning to web interfaces was challenging. Understanding layout boxes, styling tags, and asynchronous DOM manipulations in JavaScript felt overwhelming. However, building static components from scratch made me realize the potential of UI engineering.

  • Debugging is just detective work.
  • Responsive styling is essential from day one.

Full Stack 2026

Stepping into MERN

Knowing HTML, CSS, and JS was not enough. I expanded into React for state management, Node/Express for API route handling, and MongoDB Atlas for document storage. Developing my first internship app taught me how system layers connect.

  • Frameworks solve real integration problems.
  • Always understand backend CORS and request flows.
